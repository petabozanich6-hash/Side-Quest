## Teach
### Regrouping tens
Regrouping can happen in the tens place too. If the tens add to 10 or more, 10 tens make 1 hundred. Write the leftover tens and add the new hundred to the hundreds column.
### Worked method
To add 372 and 261: ones 2 + 1 = 3. Tens 7 + 6 = 13 tens, which is 1 hundred and 3 tens, so write 3 and carry 1 hundred. Hundreds 3 + 2 + 1 = 6. The total is 633.
### Regrouping twice
Some questions need regrouping in both places. To add 285 and 147: ones 5 + 7 = 12, write 2 and carry 1 ten. Tens 8 + 4 + 1 = 13, write 3 and carry 1 hundred. Hundreds 2 + 1 + 1 = 4. The total is 432.
### Always work right to left
Start with the ones, then tens, then hundreds, because anything carried moves one place to the left. Check each column before you move on, {{name}}.
