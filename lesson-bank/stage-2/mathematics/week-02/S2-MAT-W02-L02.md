## Teach
### When the ones add to 10 or more
Sometimes the ones add to more than 9. Take 6 + 7 = 13. You cannot fit 13 in the ones place, so you regroup: 13 ones is 1 ten and 3 ones. Write 3 in the ones place and add the new ten to the tens column.
### Step by step
To add 325 and 48, start with the ones: 5 + 8 = 13, so write 3 and regroup 1 ten. Add the tens: 2 + 4 + 1 = 7 tens. Add the hundreds: 3 + 0 = 3. The total is 373.
### Using blocks
Picture 13 small cubes. Ten of them swap for one long, leaving 3 cubes. The long goes into the tens column. Regrouping never changes the total, only how it is shown.
### Written layout
Write the numbers one above the other with the digits lined up by place. Start at the ones on the right. Small carried digits go above the tens column.
