## Warm-up
- 456 + 198 :: 654
- 283 + 99 :: 382
- 250 + 250 :: 500
- Round 296 to the nearest hundred. :: 300
## Teach
### Estimating first
Before you add, estimate. Round each number to the nearest 100 and add. For 296 + 408, round to 300 + 400 = 700. The exact answer should be close to 700.
### Checking your answer
After adding, compare with your estimate. 296 + 408 = 704, which is close to 700, so it makes sense. You can also check by adding the numbers in the opposite order, since 408 + 296 must give the same total.
### Solving word problems
Read the problem twice. Circle the numbers and underline the question. Decide whether you are joining or combining groups, then add. Write the answer with its units.
### Missing numbers
Sometimes one number is missing, as in ___ + 200 = 570. Count on from 200 to 570 to find the missing number, which is 370. Check by adding it back, {{name}}.
## Worked examples
- Estimate and then add 296 + 408. :: Estimate 300 + 400 = 700. Exact: ones 6 + 8 = 14, tens 9 + 0 + 1 = 10, hundreds 2 + 4 + 1 = 7. :: 704
- A shop sells 345 apples and 287 pears. How many pieces of fruit? :: Estimate 300 + 300 = 600. Exact: 5 + 7 = 12, 4 + 8 + 1 = 13, 3 + 2 + 1 = 6. :: 632 pieces
- ___ + 100 = 450 :: Count on from 100 to 450. :: 350
## Guided practice

## Quiz
- 213 + 429 :: 632 | 642 | 652 :: 642 :: 3 + 9 = 12, 1 + 2 + 1 = 4, 2 + 4 = 6.
- A good estimate for 398 + 203 is :: 500 | 600 | 700 :: 600 :: 400 + 200 = 600.
- 307 + 285 :: 582 | 592 | 602 :: 592 :: 7 + 5 = 12, 0 + 8 + 1 = 9, 3 + 2 = 5.
