# Year 3: Compare and order whole numbers

Become a Number Investigator! Use place groups to solve compare and order whole numbers tasks and explain how you checked.

Learning intention: We are learning to compare and order whole numbers within the range to 10,000.

Duration: 60 minutes.

Success criteria:
- I can read a numeral through its place groups.
- I can match a digit to its value.
- I can show a correct partition or comparison.
- I can check an answer and explain my reason.

## Teaching 1: Compare equal-sized groups first

**Comparison asks which whole is larger.**
For positive whole numbers, first check how many places are needed. A number with an additional leading non-zero place is larger. For equal-length numerals, compare their highest places first.

**Find the first difference from the left.**
If the highest digits match, move one column right. Stop at the first unequal pair. That larger place outweighs all the lower places that follow.

**Use the pair 4,518 and 4,026.**
The first unequal digits from the left determine the comparison. A larger final ones digit cannot overcome a smaller earlier thousands or hundreds digit. Think about group size, not just digit size.

Line up matching columns. Leading zeroes do not create a larger positive value; the first non-zero place matters.

I DO:
Compare 4,518 with 4,026. I line up the columns, move from the left and locate the first difference. 4,518 is greater.

YOU TRY:
Compare 4,517 and 4,518. Which first unequal column decides it?

CHECK:
4,518 is greater by one. Most leading places match, so the difference is near the right; begin from the left anyway.

Diagram: A place-value chart for 4,518. Thousands: digit 4, value 4,000, Hundreds: digit 5, value 500, Tens: digit 1, value 10, Ones: digit 8, value 8.

A digit’s column gives its value.

Notice: Compare the first unequal place, not whichever single digit catches your eye.

**Question:** For equal-length positive whole numbers, where should comparison start?

1. At whichever digit is brightest
2. At the largest place on the left
3. At the ones every time
4. At the number of commas

Reviewer answer: At the largest place on the left

Why: The largest place carries the greatest unit value. Compare it first, then move right only if it matches.

### Help with this step

1. Look at the first unequal place from the left.
2. Line up matching places and move right only while they match.
3. Compare the two group values at the first difference; later smaller places cannot reverse it.

## Teaching 2: Read comparison symbols as statements

**The symbols record a relationship.**
The sign > means is greater than; < means is less than; = means is equal to. Read the whole statement aloud rather than remembering only a shape.

**The open side faces the greater number.**
The pointed side faces the lesser number. This is a helpful shape check after deciding the actual values. Do not let the shape replace comparing the numbers.

**Order of writing matters.**
If you swap the positions of unequal numbers, the sign changes direction. The underlying relationship remains the same. Equality is different: swapping equal values keeps equality true.

Explain in words first if a sign is confusing. Then check that the symbol says the same thing.

I DO:
4,518 > 4,026: four thousand five hundred and eighteen is greater than four thousand and twenty-six.
Reversed: 4,026 < 4,518.

YOU TRY:
Write the two values in the opposite order and read your sign aloud.

CHECK:
The reversed statement uses the opposite direction but still says that 4,518 is the larger value.

Notice: A comparison statement should be true when read from left to right.

**Question:** Which comparison is true?

1. 4,518 < 4,026
2. 4,518 = 4,026
3. 4,518 > 4,026
4. 4,026 > 4,518

Reviewer answer: 4,518 > 4,026

Why: The first unequal place shows the first value is greater; the symbol must record that direction.

### Help with this step

1. Read the model comparison aloud from left to right.
2. Decide the greater value before choosing the sign direction.
3. Keep the open side beside the greater value and read the reversed statement as a check.

Learner pause: the final line pauses before continuing.

**Ascending means least to greatest.**
Descending means greatest to least. Read which direction the task requests before sorting a set. Sorting correctly in the wrong direction still answers a different question.

**Find one end of the order first.**
For ascending order, choose the least value and set it aside. Compare the remaining values to choose the next. Repeating this method keeps the whole set organised.

**Check neighbours when finished.**
Every value in an ascending list should be no greater than the next. Check the whole list, not only the first and last values. Repeated equal values can sit together.

You can use separate paper slips or a typed list. The method should work without an app doing the ordering for you.

I DO:
Set: 4,618, 4,026, 4,518.
Ascending order: 4,026, 4,518, 4,618.
I compare each neighbouring pair to check the order.

YOU TRY:
Put 4,519, 4,517, 4,518 in descending order.

CHECK:
4,519, 4,518, 4,517. The values become smaller at each step.

Notice: Read ascending or descending first. A memorised sorting direction will not answer every task.

**Question:** What does descending order mean?

1. Least to greatest
2. An order chosen at random
3. Only even values
4. Greatest to least

Reviewer answer: Greatest to least

Why: Descending order moves from the greatest value down to the least. Ascending is the other direction.

### Help with this step

1. Look at the requested ascending or descending direction.
2. Choose the least or greatest remaining value one at a time.
3. Record each value once, then check all neighbouring comparisons.

## Teaching 4: Justify rather than only announce

**A reason shows the comparison method.**
“I know it is bigger” gives no evidence. Name the first unequal place and explain which value is larger there. A precise reason can help someone check your answer.

**Keep digit and value labels clear.**
A five in the hundreds place contributes five hundred, not five. Refer to hundreds or thousands when that is the deciding place. This explains why a lower ones digit cannot reverse the result.

**Use a second check where helpful.**
You can calculate a difference or place the values on a number line. The larger value lies farther right. This check should support the place-value reasoning, not contradict it.

Choose one short explanation that answers why. A long list of every digit is unnecessary when the first difference already settles the comparison.

I DO:
For 4,518 and 4,026, I point to the first unequal column and compare its unit values. Lower places cannot reverse that difference.
Check: 4,518 - 4,026 = 492, a positive difference.

YOU TRY:
Explain why 4,618 exceeds 4,518 using the amount between them.

CHECK:
It is one hundred greater. That gives a specific value reason instead of only repeating greater.

Notice: A justification needs a deciding detail or value relationship, not a repeated judgement.

**Question:** Which is a useful comparison reason?

1. Name the first unequal place and compare its values
2. Choose the number with the most attractive digits
3. Say bigger because it is bigger
4. Compare only the final digit regardless of earlier places

Reviewer answer: Name the first unequal place and compare its values

Why: The first unequal place provides the decisive evidence for equal-length positive whole-number comparisons.

### Help with this step

1. Find the deciding place or positive difference in the model.
2. Choose evidence that explains the relationship instead of repeating greater.
3. Name the first unequal unit values or a correct difference and connect them to the conclusion.

## Put it all together

I DO: Complete a connected compare and order whole numbers record.
Target numeral: 4,518. Words: four thousand five hundred and eighteen.
Standard partition: 4,000 + 500 + 10 + 8.
Hundreds digit: 5; value: 500.
Another partition: 4,418 + 100 = 4,518.
Comparison: 4,518 > 4,026. I compare matching places from the left; the first unequal place decides. The difference is 492.
Ascending set: 4,026, 4,518, 4,618.

WHY THE REPRESENTATIONS AGREE
The written numeral, words and expanded sum describe the same place groups. The non-standard partition also returns the same total. Comparing uses those group values, not only the shape of a single digit.

COMMON MISTAKE AND FIX
Writing the hundreds digit’s value as 5 loses its unit size. I change the value label to 500. Another possible error is deleting the zero in 4,026; I keep its column and reread the whole count.

CHECK
I rebuild the numeral from its non-zero terms and read the comparison in both directions. If a check disagrees, I revisit the relevant column before changing unrelated digits.

Diagram: A place-value chart for 4,026. Thousands: digit 4, value 4,000, Hundreds: digit 0, value 0, Tens: digit 2, value 20, Ones: digit 6, value 6.

A digit’s column gives its value.

### Help with this step

1. Read the numeral and expanded form together.
2. Match each part of the sum to its place column.
3. Rebuild the same total, then use matching place values to check the comparison.
