## Teaching 1: Locate a digit before naming its value

**A place is a position in the numeral.**
Start with ones on the right, then tens, hundreds, thousands and ten thousands as needed. Moving left makes the unit ten times as large. You can label a chart before inserting digits.

**A face digit does not state its value.**
The written five always looks like five, but can mean five ones, five tens or five hundreds. Multiply the digit by the place unit, or say that many groups of the unit.

**Apply it to 4,518.**
The hundreds digit is 5. Its value is 500. The ones digit is 8; its value is 8. Those are counts of different-sized units.

Point to the column, name the unit, then give the value. That order prevents an answer based only on the shape of the digit.

I DO:
4,518: hundreds column → digit 5 → 5 hundreds → value 500.

YOU TRY:
Find the tens digit and its value before checking.

CHECK:
The tens digit is 1, so it contributes 10. The digit and its value need different labels.

Diagram: A place-value chart for 4,518. Thousands: digit 4, value 4,000, Hundreds: digit 5, value 500, Tens: digit 1, value 10, Ones: digit 8, value 8.

A digit’s column gives its value.

Notice: A digit answer and a value answer can look different. Read what the question asks.

**Question:** What is the value of the hundreds digit in 4,518?

1. 5
2. 500
3. 50
4. 5000

Reviewer answer: 500

Why: The digit is in the hundreds column, so its value is that many hundreds.

### Help with this step

1. Look at the column rather than only the digit shape.
2. Name its unit, then count how many of that unit the digit represents.
3. Record digit and value with different labels; multiply by the column unit for the value.

## Teaching 2: Partition without changing the total

**Partition means split a whole into parts.**
In standard expanded form, split a numeral into the value contributed by each non-zero place. Add those contributions to reconstruct the same total.

**Match each term to a column.**
A term such as five hundred describes the value of a digit in the hundreds place. Writing five instead would lose the unit size. Use addition signs because the parts combine into one total.

**Show the full model.**
4,518 = 4,000 + 500 + 10 + 8. Read each part, then check the sum. You have represented the same number another way, not made a smaller number.

Zero-valued terms can be left out of the addition, but do not shift other digits in the numeral. Keep those two representations distinct.

I DO:
I split 4,518 into its non-zero place values: 4,000 + 500 + 10 + 8.
I put each part back into a chart and recover 4,518.

YOU TRY:
Partition 4,026. Include the value of every non-zero digit.

CHECK:
4,000 + 20 + 6 adds to 4,026. A zero place contributes nothing to this sum but remains in the numeral.

Notice: An expanded term includes its unit value. Listing the face digits alone is not standard expanded form.

**Question:** What must a standard expanded-form term show?

1. Only the face digit with no place value
2. The number of letters in the word
3. The value contributed by its place
4. A new unrelated count

Reviewer answer: The value contributed by its place

Why: A standard expanded term gives the contribution of a place, so the terms add back to the original number.

### Help with this step

1. Look at each expanded term beside its place column.
2. Write the value of each non-empty group instead of only its digit.
3. Add the terms back and check that the original numeral returns.

## Teaching 3: Regroup the parts flexibly

### In-site episode: Explain place value and partitions in action

Pip: I am practising how to regroup the parts flexibly. I need to track the value, not just copy digits.
Juno: The same total can have different partitions.
You can exchange one hundred for ten tens or one thousand for ten hundreds. An exchange preserves the total because the groups have equal value. This can help with later calculation.
Pip: I take one hundred from 4,518: 4,418 remains. I record the removed part too: 4,418 + 100 = 4,518.
If I write only 4,418, I have lost a hundred rather than repartitioned.
Juno: Pause and try a fresh example with the same check. Explain what stays unchanged or which value relationship settles the result.

Learner pause: the final line pauses before continuing.

**The same total can have different partitions.**
You can exchange one hundred for ten tens or one thousand for ten hundreds. An exchange preserves the total because the groups have equal value. This can help with later calculation.

**Show both sides of the exchange.**
Reducing a larger group requires adding the equivalent smaller groups. Removing a hundred without adding ten tens would reduce the total. Use an equality to record the unchanged count.

**Try a non-standard partition.**
4,518 = 4,418 + 100. It is also 3,518 + 1,000. These differ from standard expanded form but still make the same whole. Check by addition rather than judging the length of the expression.

A correct partition has parts that add to the target. It does not need a particular number of terms unless the question requests one.

I DO:
I take one hundred from 4,518: 4,418 remains. I record the removed part too: 4,418 + 100 = 4,518.
If I write only 4,418, I have lost a hundred rather than repartitioned.

YOU TRY:
Use 4,508 as the first part of a partition of 4,518. What second part preserves the total?

CHECK:
Add ten. The two parts then sum to 4,518.

Notice: An exchange changes grouping, not the total. Always check what was removed and what was added.

**Question:** What should remain unchanged when regrouping a number?

1. Every face digit in every representation
2. The number of written terms
3. The size of all groups
4. The total value

Reviewer answer: The total value

Why: Regrouping exchanges equal values, so the total is unchanged even if the grouping or written digits change.

### Help with this step

1. Look at the model that sets aside a larger group.
2. Keep a record of the removed value and the part remaining.
3. Add both parts to test the unchanged total; do not drop a group from the record.

## Teaching 4: Use place value to explain a change

**Changing one group changes a known amount.**
Adding a hundred adds one group of one hundred; adding a ten adds one group of ten. Read the unit in the question before changing a digit.

**Check whether regrouping is needed.**
If a column already has nine groups, adding another completes a larger group. If it has room for another group, only that column changes. Explain the value change rather than guessing a new digit.

**Verify with a difference.**
Subtract the original count from your proposed count, or count back the added group. The difference should match the intended amount. A new numeral can look plausible and still show the wrong-sized change.

Draw a chart or write a partition when you need support. The purpose is a clear value explanation, not the fastest possible mental answer.

I DO:
4,518 + 100 = 4,618. I added one hundred, not one unit.
Check: 4,618 - 4,518 = 100.

YOU TRY:
Add ten to 4,518, then say what group you added.

CHECK:
The result is 4,528. It is one ten greater. The difference check confirms the intended size.

Notice: Say the amount added. Do not confuse the place name with a one-unit counting step.

**Question:** What is 4,518 plus one hundred?

1. 4618
2. 4519
3. 4528
4. 5518

Reviewer answer: 4618

Why: One hundred changes the total by exactly one hundred, not by a one-unit or one-thousand step.

### Help with this step

1. Look at whether the added quantity is a unit, ten or hundred.
2. Identify the amount before changing the numeral.
3. Add the specified group and count that same amount back to verify the original.

## Put it all together

I DO: Complete a connected explain place value and partitions record.
Target numeral: 4,518. Words: four thousand five hundred and eighteen.
Standard partition: 4,000 + 500 + 10 + 8.
Hundreds digit: 5; value: 500.
Another partition: 4,418 + 100 = 4,518.
Comparison: 4,518 > 4,026. I compare matching places from the left; the first unequal place decides. The difference is 492.
Ascending set: 4,026, 4,518, 4,618.

WHY THE REPRESENTATIONS AGREE
The written numeral, words and expanded sum describe the same place groups. The non-standard partition also returns the same total. Comparing uses those group values, not only the shape of a single digit.

COMMON MISTAKE AND FIX
Writing the hundreds digit’s value as 5 loses its unit size. I change the value label to 500. Another possible error is deleting the zero in 4,026; I keep its column and reread the whole count.

CHECK
I rebuild the numeral from its non-zero terms and read the comparison in both directions. If a check disagrees, I revisit the relevant column before changing unrelated digits.
