# Year 3: Whole-number fluency with reasons

Become a Number Investigator! Use place groups to solve whole-number fluency with reasons tasks and explain how you checked.

Learning intention: We are learning to whole-number fluency with reasons within the range to 10,000.

Duration: 60 minutes.

Success criteria:
- I can read a numeral through its place groups.
- I can match a digit to its value.
- I can show a correct partition or comparison.

## Teaching 1: Read the digits through their places

**Digit and value are different.**
A digit is a written symbol from zero to nine. Its value depends on the place. A four in the hundreds column means four hundreds; in the ones column it means four ones.

**Read a useful chunk.**
In 4,518, separate the thousands part from the final three digits. Read the thousands part, then the hundreds, tens and ones that follow. A space or comma can help group digits; it does not mean a decimal point.

**Say the number in words.**
Our model is “four thousand five hundred and eighteen”. Say the number, point to each matching part and check that you did not turn a digit into the wrong-sized group.

The same method works with fewer or more non-zero places. The number of digits gives a starting clue, but the position of each digit settles its value.

I DO:
4,518 = 4,000 + 500 + 10 + 8.
Words: four thousand five hundred and eighteen.
I match each spoken group with its column, then read the whole count once.

YOU TRY:
Read 4,026 using the columns. Try before comparing.

CHECK:
It is four thousand and twenty-six. The zero column contributes no groups of that size, but still holds its place.

Diagram: A place-value chart for 4,518. Thousands: digit 4, value 4,000, Hundreds: digit 5, value 500, Tens: digit 1, value 10, Ones: digit 8, value 8.

A digit’s column gives its value.

Notice: Do not read every digit as a separate number name when the task asks for the whole number.

**Question:** Which words correctly read 4,518?

1. four thousand six hundred and eighteen
2. four thousand four hundred and eighteen
3. four thousand five hundred and eighteen
4. four thousand five hundred and twenty-eight

Reviewer answer: four thousand five hundred and eighteen

Why: Four thousand five hundred and eighteen matches the thousands part and the remaining hundreds, tens and ones. The other readings change a digit’s value.

### Help with this step

1. Look at how the thousands chunk and final digits are read.
2. Point to the matching place while saying each number-word part.
3. Read the large group first, then the remaining hundreds, tens and ones; match the result back to the chart.

## Teaching 2: Partition without changing the total

**Partition means split a whole into parts.**
In standard expanded form, split a numeral into the value contributed by each non-zero place. Add those contributions to reconstruct the same total.

**Match each term to a column.**
A term such as five hundred describes the value of a digit in the hundreds place. Writing five instead would lose the unit size. Use addition signs because the parts combine into one total.

**Show the full model.**
4,518 = 4,000 + 500 + 10 + 8. Read each part, then check the sum. You have represented the same number another way, not made a smaller number.

Zero-valued terms can be left out of the addition, but do not shift other digits in the numeral. Keep those two representations distinct.

I DO:
I split 4,518 into its non-zero place values: 4,000 + 500 + 10 + 8.
I put each part back into a chart and recover 4,518.

YOU TRY:
Partition 4,026. Include the value of every non-zero digit.

CHECK:
4,000 + 20 + 6 adds to 4,026. A zero place contributes nothing to this sum but remains in the numeral.

Notice: An expanded term includes its unit value. Listing the face digits alone is not standard expanded form.

**Question:** What must a standard expanded-form term show?

1. Only the face digit with no place value
2. The number of letters in the word
3. The value contributed by its place
4. A new unrelated count

Reviewer answer: The value contributed by its place

Why: A standard expanded term gives the contribution of a place, so the terms add back to the original number.

### Help with this step

1. Look at each expanded term beside its place column.
2. Write the value of each non-empty group instead of only its digit.
3. Add the terms back and check that the original numeral returns.

## Teaching 3: Compare equal-sized groups first

### In-site episode: Whole-number fluency with reasons in action

Pip: I am practising how to compare equal-sized groups first. I need to track the value, not just copy digits.
Juno: Comparison asks which whole is larger.
For positive whole numbers, first check how many places are needed. A number with an additional leading non-zero place is larger. For equal-length numerals, compare their highest places first.
Pip: Compare 4,518 with 4,026. I line up the columns, move from the left and locate the first difference. 4,518 is greater.
Juno: Pause and try a fresh example with the same check. Explain what stays unchanged or which value relationship settles the result.

Learner pause: the final line pauses before continuing.

**Comparison asks which whole is larger.**
For positive whole numbers, first check how many places are needed. A number with an additional leading non-zero place is larger. For equal-length numerals, compare their highest places first.

**Find the first difference from the left.**
If the highest digits match, move one column right. Stop at the first unequal pair. That larger place outweighs all the lower places that follow.

**Use the pair 4,518 and 4,026.**
The first unequal digits from the left determine the comparison. A larger final ones digit cannot overcome a smaller earlier thousands or hundreds digit. Think about group size, not just digit size.

Line up matching columns. Leading zeroes do not create a larger positive value; the first non-zero place matters.

I DO:
Compare 4,518 with 4,026. I line up the columns, move from the left and locate the first difference. 4,518 is greater.

YOU TRY:
Compare 4,517 and 4,518. Which first unequal column decides it?

CHECK:
4,518 is greater by one. Most leading places match, so the difference is near the right; begin from the left anyway.

Notice: Compare the first unequal place, not whichever single digit catches your eye.

**Question:** For equal-length positive whole numbers, where should comparison start?

1. At whichever digit is brightest
2. At the largest place on the left
3. At the ones every time
4. At the number of commas

Reviewer answer: At the largest place on the left

Why: The largest place carries the greatest unit value. Compare it first, then move right only if it matches.

### Help with this step

1. Look at the first unequal place from the left.
2. Line up matching places and move right only while they match.
3. Compare the two group values at the first difference; later smaller places cannot reverse it.

## Teaching 4: Choose a check before speed

**Fluency includes accuracy and useful method choice.**
It is not just finishing quickly. Read what a task asks: number words, a digit value, a partition or a comparison. Choosing the wrong operation quickly does not help.

**Predict a sensible answer.**
A count should keep its group sizes. A partition should sum to the same whole. A comparison should agree with the first unequal place. Use these expectations to catch a misplaced zero or a wrong-sized change.

**Check with another representation.**
Read a numeral back from words; rebuild it from a partition; reverse a comparison statement and read its sign. This compares meanings rather than simply repeating the same writing.

Keep a before-and-after note if you repair an error. If your first answer was correct, describe the check that confirmed it. You do not need to invent a mistake.

I DO:
Attempt: 4,518 = 4,418 + 10.
I add the parts and get 4,428, not 4,518. I repair the last part to 100 and check the total again.

YOU TRY:
Check the statement 4,518 = 4,508 + 10 using the total.

CHECK:
It is correct: the two parts add to 4,518. Accuracy comes from the value check, not the length of the expression.

Notice: Use a check suited to the task. Recopying the same unexamined answer does not confirm it.

**Question:** Which check confirms a partition?

1. Count its plus signs only
2. Add the parts and compare with the target
3. Remove every zero
4. Choose the longest expression

Reviewer answer: Add the parts and compare with the target

Why: A partition is valid when its parts add to the original total. Its visual length does not settle correctness.

### Help with this step

1. Look at the task’s requested representation.
2. Choose a different way to test the same total or relationship.
3. Add a partition back, read words into a numeral or reverse a comparison to check its meaning.

## Put it all together

I DO: Complete a connected whole-number fluency with reasons record.
Target numeral: 4,518. Words: four thousand five hundred and eighteen.
Standard partition: 4,000 + 500 + 10 + 8.
Hundreds digit: 5; value: 500.
Another partition: 4,418 + 100 = 4,518.
Comparison: 4,518 > 4,026. I compare matching places from the left; the first unequal place decides. The difference is 492.
Ascending set: 4,026, 4,518, 4,618.

WHY THE REPRESENTATIONS AGREE
The written numeral, words and expanded sum describe the same place groups. The non-standard partition also returns the same total. Comparing uses those group values, not only the shape of a single digit.

COMMON MISTAKE AND FIX
Writing the hundreds digit’s value as 5 loses its unit size. I change the value label to 500. Another possible error is deleting the zero in 4,026; I keep its column and reread the whole count.

CHECK
I rebuild the numeral from its non-zero terms and read the comparison in both directions. If a check disagrees, I revisit the relevant column before changing unrelated digits.

Diagram: A place-value chart for 4,026. Thousands: digit 4, value 4,000, Hundreds: digit 0, value 0, Tens: digit 2, value 20, Ones: digit 6, value 6.

A digit’s column gives its value.

### Help with this step

1. Read the numeral and expanded form together.
2. Match each part of the sum to its place column.
3. Rebuild the same total, then use matching place values to check the comparison.
