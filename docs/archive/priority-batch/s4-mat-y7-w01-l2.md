## Teaching 1: Order by position, not digit size

**Greater values lie farther right.**
This rule includes negative integers, zero and positive integers. On the line, negative two lies right of negative five, so negative two is greater. The numeral five being larger than two does not reverse their signed positions.

**Compare across zero first.**
A positive integer is greater than zero; zero is greater than a negative integer. If the two values lie on opposite sides, their positions already determine the comparison.

**Compare two negatives carefully.**
The one closer to zero lies farther right and is greater. The one with a larger distance from zero lies farther left and is smaller. That statement concerns two negative values, not all possible numbers.

Locate both points or sketch the relevant interval before recording a sign. Explain position as evidence.

I DO:
−2 > −5 because −2 lies to the right of −5.
−5 < 1 because −5 is left of zero and 1 is right of zero.

YOU TRY:
Compare −4 and −1 on a number line.

CHECK:
−4 < −1. Negative one is nearer zero and farther right, so it is the greater signed value.

Position and distance from zero answer different questions.

Notice: A larger absolute value does not mean a larger signed value.

## Teaching 2: Use signs that match a spoken relationship

**Read the complete comparison aloud.**
The symbol < says is less than; > says is greater than; = says is equal to. Treat the statement as a relationship, not a picture to memorise independently of the values.

**The sign’s open side faces the greater value.**
Decide which signed value is greater first. Then check the symbol’s direction. Negative signs belong to the numbers and must not be dropped when reading the comparison.

**Reversing unequal values reverses the symbol.**
If negative four is less than negative one, then negative one is greater than negative four. Both statements preserve the same relationship.

Do not confuse the comparison sign with a minus sign. One records a relationship between two values; the other marks a negative value or an operation in a different context.

I DO:
−4 < −1 reads negative four is less than negative one.
Reverse: −1 > −4.

YOU TRY:
Record a comparison between zero and negative six in both writing orders.

CHECK:
0 > −6 and −6 < 0. The negative value remains negative when its writing position changes.

Notice: Read the signs together with the numbers. A comparison of unsigned digits answers a different question.

**Question:** Which reversed statement agrees with −4 < −1?

1. −1 < −4
2. 4 < 1
3. −4 = −1
4. −1 > −4

Reviewer answer: −1 > −4

Why: Reversing the two unequal signed values reverses the comparison direction while preserving the relationship.

### Help with this step

1. Read the original statement in words.
2. Keep each number’s negative sign attached when swapping positions.
3. Write the reverse order and check that its relationship says the same thing.

**Ascending order goes from least to greatest.**
For integers, begin at the farthest-left value and move right. Descending order moves the other way. A set can contain values on both sides of zero.

**Choose one extreme at a time.**
For ascending order, find the least remaining value, record it and remove it from the remaining set. Repeat until all values are used. This avoids sorting only the negative and positive parts without connecting them.

**Check neighbouring comparisons.**
Every value must be no greater than the next in an ascending list. One misplaced negative value can make the middle wrong even when the endpoints are correct.

Use a quick line sketch to verify position. Do not put a negative value later just because its unsigned numeral is larger.

I DO:
Set: 3, −5, 0, −2.
Ascending: −5, −2, 0, 3.
Checks: −5 < −2, −2 < 0, 0 < 3.

YOU TRY:
Write 2, −4, −1, 0 in descending order.

CHECK:
2, 0, −1, −4. Every next value lies farther left.

Notice: Sorting requires every value once and the requested direction.

**Question:** Which list is ascending?

1. 3, 0, −2, −5
2. −2, −5, 0, 3
3. −5, −2, 0, 3
4. 0, −5, 3, −2

Reviewer answer: −5, −2, 0, 3

Why: The signed values move from farthest left to farthest right: −5, −2, 0, 3.

### Help with this step

1. Look at the requested direction before arranging the set.
2. Choose the least or greatest remaining value one at a time.
3. Check each neighbouring pair against its number-line position.

## Teaching 4: Interpret the comparison in context

**Value and size language need a reference.**
In temperatures, negative two degrees Celsius is warmer than negative five degrees Celsius because its value is greater on the same scale. The reading farther below zero is colder, not warmer.

**Do not compare different units as though they are one scale.**
A signed temperature and a signed height are different measurements. Integer order can compare their numerals abstractly, but a claim such as warmer requires temperature readings on the same scale.

**State a numerical and contextual conclusion.**
Write the inequality, then explain what it means for the supplied context. A correct numerical sign without the interpretation may leave the actual question unanswered.

Check whether words such as higher, colder or below refer to value or distance. Use the stated unit and reference, rather than assuming every larger magnitude is a larger reading.

I DO:
−2 °C > −5 °C. The −2 °C reading is warmer by three degrees on this scale.
I distinguish that conclusion from distance below zero: −5 °C is farther below zero.

YOU TRY:
Which is colder, −1 °C or −4 °C? Give a value reason.

CHECK:
−4 °C is colder because it is the lower reading on the same temperature scale.

Notice: A contextual word must agree with the scale, not only with the size of the unsigned numeral.

**Question:** Which reading is warmer on the same Celsius scale?

1. −2 °C rather than −5 °C
2. −5 °C because five exceeds two
3. Both must mean the same temperature
4. Any negative reading is impossible

Reviewer answer: −2 °C rather than −5 °C

Why: Negative two is the greater reading, so it is warmer on the same Celsius scale.

### Help with this step

1. Identify the common scale and unit.
2. Write the signed comparison before using the context word.
3. Explain whether the rightward or leftward value matches the requested meaning.

## Put it all together

I DO: A complete order integers and justify comparisons response.
Use a one-unit number line with zero as reference. Values: −6, 0, 4 and −2.
Ascending: −6, −2, 0, 4. Descending: 4, 0, −2, −6. −6 < −2 and 0 < 4. Of −6 °C and −2 °C, −2 °C is warmer because it is the greater reading.

WHY THE METHOD WORKS
Position represents signed value; distance from zero answers a different question. For ordering, the farther-right value is greater. Check every neighbouring pair in a sorted list.

COMMON MISTAKE AND FIX
Calling −6 greater than −2 because six exceeds two confuses distance with signed value. Locate the points and use the one farther right as the greater value.

CHECK
