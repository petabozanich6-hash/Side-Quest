# Stage 2 English Plan (Weeks 3-50) - APPROVED 2026-10-07

Status: Weeks 1 and 2 are built (plan Weeks 2 and 3, renumbered on load). This file covers app Weeks 3-50, 4 lessons per week, 192 lessons.

## Rules (from the user)
- Four lessons per week. Reading, writing, language/grammar, and spelling/vocabulary/handwriting/speaking each week.
- Substantive explicit teaching from foundations, worked examples, then guided practice, then task. Build on the established lesson format (see lesson_library_s2_english_w03_l4_full.py and the readers theatre lesson).
- Embedded, tested videos (YouTube, BBC Bitesize, Khan Academy). Check each link before use.
- Reading texts are chosen by the parent at the time. Never preselect readings.
- No Department of Education material.
- Few or no games for Stage 2 (Oliver gets absorbed). Randomise sorting item order.
- Click-to-reveal key vocabulary. Progressive cards. No reflection prompts.
- Map each lesson to every outcome it teaches. Outcomes can be combined across lessons.
- Outcome codes: EN2-OLC-01, EN2-VOCAB-01, EN2-RECOM-01, EN2-CWT-01, EN2-SPELL-01, EN2-HANDW-01.
- Build workflow: pass 1 write lessons (3-4 per push), pass 2 find and verify videos, pass 3 register in lesson_library.py and bump LESSON_LIBRARY_VERSION. Do not deploy. The user will request batch deployments.
