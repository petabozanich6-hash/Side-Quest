# Independent lesson template

Every lesson is written so the child works alone on their own computer. The parent sees outcomes, scores and evidence, and answers 'I'm stuck' flags.

## Fixed lesson structure (60 minutes)

| Part | Oliver (Stage 2) | Mason (Stage 4) | Content |
|---|---|---|---|
| 1. Warm-up and recall | 5 min | 5 min | 3 to 5 quick questions from earlier lessons (cumulative revision) |
| 2. Teach | 15 min | 15 min | Definitions, explanation and worked examples, built up with click-to-reveal cards. One embedded video or reading where it helps |
| 3. Guided practice | 10 min | 10 min | Questions with hints; answer shown after the child tries |
| 4. Break | 3 min | optional | Stand up, drink, stretch |
| 5. Independent task | 15 min | 20 min | The main piece of work, with a success checklist and a response space |
| 6. Quiz | 7 min | 7 min | Auto-marked, 5 questions, instant feedback |
| 7. Wrap-up | 5 min | 3 min | 'I can' statements ticked off; what comes next |

Oliver's lesson runs as three blocks (parts 1-3, part 5, parts 6-7) with the break between block one and block two. No games for Stage 2.

## Lesson data fields

- child, stage, subject, week, day, lesson number
- title and one-sentence goal ('By the end I can...')
- NESA outcome codes and focus area (parent side only)
- parent rationale and evidence collected (parent side only)
- recall questions
- teaching cards (ordered list: heading, text, example, optional image or emoji)
- embedded resource (type, URL, start and end time, what to notice)
- guided practice questions (question, hint, answer)
- independent task (instructions, success checklist, response type: text, upload, drawing)
- quiz questions (type, options, correct answer, explanation)
- 'I can' statements
- stuck flag (button text: 'I'm stuck', optional note, sends to parent)
- printable worksheet link (optional)

## Writing rules

1. Teach from the basics; never assume prior knowledge.
2. Short sentences for Oliver, with a picture or emoji for each idea. Plain, clear language for Mason.
3. No instruction that needs an adult to explain it.
4. Every question has a hint and an answer to check against.
5. Revisit earlier lessons in the warm-up and quiz.
6. Reading choices are left for the parent to set at the time.
7. Links must be tested before the lesson is released.

## Daily checklist

Each child sees one ordered list for the day: lesson 1, lesson 2 and so on, each with a tick when finished. Oliver gets 4 lessons a day, Mason 4 to 5.
