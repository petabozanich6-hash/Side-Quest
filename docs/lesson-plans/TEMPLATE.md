# Lesson template

Matches the fields the app stores for each lesson.

- Title, stage, year level, learning area (must match a subject card name on the Lessons page), duration in minutes
- Learning intention
- Success criteria
- Materials
- Key vocabulary
- Prior knowledge
- Explicit teaching
- Worked example
- Guided practice
- Independent task
- Response prompt and evidence requirement
- Self check
- Reflection prompt
- Offline alternative
- Accessibility notes
- Outcome codes and source note (parent verifies against NESA)
