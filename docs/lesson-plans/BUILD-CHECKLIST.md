# Build checklist

Every stage has a settled time plan. This file lists what is left to fill in, where to find it, and the steps to complete a stage when it is time to build lessons.

## Steps to complete a stage or subject

1. Open the NESA syllabus pages for the subject (links below) and copy the outcome codes and focus area or module names into the stage documents.
2. Spread the focus area or module hours across the terms in the stage file. Hours per term are already set.
3. Check implementation dates, because several syllabuses change in 2027 and 2028.
4. Write the lessons using TEMPLATE.md and record the count in the status column.
