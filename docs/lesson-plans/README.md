# Lesson plan base documents

One file per NESA stage, giving the time allocation that every premade lesson set should be built to. Build lessons to these hour totals so a home schooling program covers the curriculum within registration requirements.

| Stage | Years | File |
|---|---|---|
| Early Stage 1 | Kindergarten | early-stage-1.md |
| Stage 1 | 1-2 | stage-1.md |
| Stage 2 | 3-4 | stage-2.md |
| Stage 3 | 5-6 | stage-3.md |
| Stage 4 | 7-8 | stage-4.md |
| Stage 5 | 9-10 | stage-5.md |
| Stage 6 | 11-12 | stage-6.md |

Lesson template: TEMPLATE.md. These documents set time and structure only. Lesson content comes from the NESA syllabus for each subject and stage.

All stages assume 40 teaching weeks a year, as four terms of 10 weeks.

Sources: NSW Government home schooling guidelines and time allocation guidance, NESA curriculum pages for Years 7-10 and 11-12. Hours are planning guidance. Verify against the current syllabus before building lessons.
