# Document Studio: Square export

Owner HQ > Document Studio is an independent product creation workshop. It does **not** create listings, fulfil orders, collect customer information, or publish directly to Square.

## Authoring

Choose a starter (worksheet, family planner, reading journal, evidence tracker or checklist), then edit the title, audience, instructions and activities. Activity layouts currently support writing/reflection boxes, interactive checklists and dated three-column logs. Drafts are saved **only in the current browser** using local storage; they are not synchronised across devices or backed up to the server.

## Exports

"Create print + fillable PDF set" calls an owner-only API to build the same content in two A4 PDFs. The **print** edition has visible boxes, writing guides and checklist outlines. The **fillable** edition includes PDF AcroForm text/checkbox widgets in the same areas. Long activities continue on additional sheets; the renderer does not shrink answer spaces to force a page count. Covers use a restrained forest-green, bronze and white Side-Quest visual system.

Download files individually or use **Download Square product ZIP** to package both PDFs with owner-only listing and quality notes. No product database row or customer transaction is created during export.

## Mandatory pre-sale test

1. Inspect all pages at full size and print an A4 sample: check margins, contrast, labels, table continuation, whitespace, answer sizes and page count.
2. Open the fillable PDF in common PDF readers, enter longer realistic text, tick each type of checkbox, save, close, reopen, print and confirm fields retain the entered values.
3. Independently proofread accuracy, age appropriateness, activity directions, illustrations (if added externally), answers, sources and rights for sale.
4. For jurisdiction-specific planning products, apply the source-review and independent release standard in HOME_EDUCATION_DOCUMENT_QUALITY.md before making claims about suitability. These exports are not government forms or registration approvals.
5. Check the customer's actual Square digital delivery, download recovery and package contents using a test purchase before enabling a listing.

## Current boundaries

This workflow is a structured layout and export editor, **not** a general illustration/AI design engine. It does not generate crosswords, colour-in graphics, teacher-verified answers, interactive drag-and-drop PDFs or independently review curriculum accuracy. The PDF renderer uses standard PDF Helvetica fonts, replacing unsupported symbols where needed; inspect every product for typography issues. It does not perform a visual pixel-by-pixel PDF QA pass. PDF form compatibility and typed-answer overflow still require a real reader test.

Never describe these owner-generated files as "ready for sale" solely because they have passed the automatic structural checks. The existing legacy Side-Quest shop/release controls remain separately available and are not invoked by Square exports.
