## Teaching 1: Define rational numbers with an exact fraction

**A rational number can be written as a ratio of integers.**
The form is a/b, where a and b are integers and b is not zero. The fraction describes an exact value. One half, negative three quarters and five all qualify: five can be written as five over one.

**A denominator cannot be zero.**
Division by zero does not give an ordinary number in this definition. A fraction with zero on top and a non-zero denominator is different: zero over five equals zero and is rational.

**Different forms can name the same value.**
One half and two quarters are equal. A decimal such as 0.5 equals one half. Classify the value rather than treating each notation as a separate kind of number.

State an exact fraction as evidence when you can. A numeral’s visual length is not a classification rule.

I DO:
0.75 = 75/100 = 3/4, so it is rational.
−3 = −3/1, so negative integers are rational too.

YOU TRY:
Give a fraction for 0.2 and classify it.

CHECK:
0.2 = 2/10 = 1/5. Its exact integer-ratio representation makes it rational.

## Teaching 2: Distinguish terminating and recurring decimals

**A terminating decimal stops.**
For example, 0.125 has a final displayed digit and equals 125/1000. Every finite decimal can be written with a power-of-ten denominator, so it is rational.

**A recurring decimal repeats a pattern forever.**
One third is 0.333… where the threes continue indefinitely. It does not terminate, but it is rational because the exact value is one third. A repeating block may contain several digits.

**Dots need a stated meaning.**
An ellipsis alone does not tell you whether every later digit repeats. Here we explicitly state when a decimal is recurring. A short calculator display may be only a rounded approximation to a longer decimal.

Do not classify every non-terminating decimal as irrational. The recurring pattern is the important distinction in this explanation.

I DO:
0.125 terminates and equals 1/8.
0.333… with threes repeating forever equals 1/3, so it is rational too.

YOU TRY:
Classify 0.6 and 0.666… with sixes recurring forever.

CHECK:
Both are rational. The first equals 3/5; the second equals 2/3. Their different decimal forms do not exclude either from the integer-ratio definition.

Notice: A recurring decimal is non-terminating but rational. A rounded display is not the full exact value.

Why: This exact recurring decimal equals 1/3, a ratio of integers.

**An irrational number is not an exact ratio of integers.**
Its decimal representation does not terminate or repeat a fixed block forever. The square root of two and pi are examples. This lesson uses those established examples; it does not prove their irrationality.

**An approximation is a different value.**
The square root of two is about 1.414, but not exactly 1.414. The finite decimal 1.414 is rational because it equals 1414/1000. Approximating an irrational value does not make the exact value rational.

**Use the approximate sign carefully.**
The symbol ≈ means approximately equal. Use it for a rounded decimal, while = claims exact equality. Write √2 ≈ 1.414 when using that three-decimal approximation.

Avoid classifying an exact value from a few displayed digits. Identify what the symbol or problem actually specifies.

I DO:
Exact value: √2, irrational.
Approximation: 1.414, rational as a finite decimal.
Record: √2 ≈ 1.414, not √2 = 1.414.

YOU TRY:

CHECK:
3.14 is a finite rational decimal; pi is a different exact value with a non-terminating, non-recurring decimal representation.

Notice: Exact and approximate are different labels. Keep them attached to the intended value.

## Teaching 4: Classify real numbers with a reason

**Real numbers include rational and irrational values.**
They can be represented as positions on a number line. Integers sit inside the rational group, and rational and irrational together make the real-number group studied here.

**Ask for evidence, not appearance.**
An exact fraction, integer or terminating/recurring decimal supports rational classification. An established irrational value such as √2 needs its exact identity preserved. A square-root symbol alone does not imply irrationality: √9 is exactly three.

**State the category and why.**
Use “This value is rational because ____” or “The exact value is irrational; its displayed decimal is only an approximation.” Do not use positivity, number of digits or neatness as a reason.

If an unfamiliar decimal is only partly shown and no pattern is specified, the display may not supply enough information. Say what evidence is missing instead of guessing the exact value.

I DO:
√9 = 3 = 3/1, so it is rational.
√2 is irrational as an exact value.
−0.5 = −1/2, so it is rational.

YOU TRY:
Classify 7 and give an integer-ratio reason.

CHECK:
7 is rational because 7 = 7/1. Being an integer also places it within the rational numbers.

Notice: A radical sign is notation, not a guarantee of irrationality.

**Question:** Why is √9 rational?

1. Every root is irrational
2. It equals exactly 3, which can be written as 3/1
3. It has only one printed digit
4. It is a positive symbol

Reviewer answer: It equals exactly 3, which can be written as 3/1

Why: The principal root of nine is exactly three, an integer ratio with non-zero denominator.

### Help with this step

1. Look for an exact equivalent before assigning a category.
2. Check whether a root gives an integer or an established irrational value.
3. State a fraction or exact-value reason; avoid judging the shape of the notation.
