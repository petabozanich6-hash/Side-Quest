# Year 3: Read and count whole numbers

Become a Number Investigator! Use place groups to solve read and count whole numbers tasks and explain how you checked.

Learning intention: We are learning to read and count whole numbers within the range to 10,000.

Duration: 60 minutes.

Success criteria:
- I can read a numeral through its place groups.
- I can match a digit to its value.
- I can show a correct partition or comparison.
- I can check an answer and explain my reason.

## Teaching 1: Build the number from equal groups

**A whole number counts complete units.**
An item count such as a number of cards uses whole units, not parts of one card. Large counts are organised into equal groups so we do not have to count every item again.

**Each place is ten times the place to its right.**
Ten ones make a ten. Ten tens make a hundred. Ten hundreds make a thousand. Ten thousands make a ten thousand. Picture bundling ten small groups into one larger group. The written places record how many of each group there are.

**Keep the range in view.**
Today we read whole numbers up to 10,000. A new place appears when every lower place reaches nine and one more unit is added. This is a change in grouping, not a new kind of number.

Start at the ones place on the right. Name each column before reading its digit; a digit’s shape alone does not tell its value.

I DO:
4,518 has 8 ones at the right. The next column records tens, then hundreds, then thousands. I use columns instead of counting 4,518 individual cards.

YOU TRY:
How many tens make one hundred? Use equal bundles before checking.

CHECK:
Ten tens make one hundred because ten groups of ten contain a hundred units. It is not one ten with a different name.

Diagram: A place-value chart for 4,518. Thousands: digit 4, value 4,000, Hundreds: digit 5, value 500, Tens: digit 1, value 10, Ones: digit 8, value 8.

A digit’s column gives its value.

Notice: Read from the right to identify places, then from the left to say the whole number.

**Question:** What happens when ten hundreds are grouped together?

1. They become ten ones
2. They become one thousand
3. They become one hundred
4. They disappear from the count

Reviewer answer: They become one thousand

Why: Ten groups of one hundred contain one thousand units. Regrouping changes the grouping, not the total.

### Help with this step

1. Look back at equal bundles making the next larger unit.
2. Name the unit in each column before reading its digit.
3. Start at ones, then use each tenfold grouping to name the next place.

## Teaching 2: Read the digits through their places

**Digit and value are different.**
A digit is a written symbol from zero to nine. Its value depends on the place. A four in the hundreds column means four hundreds; in the ones column it means four ones.

**Read a useful chunk.**
In 4,518, separate the thousands part from the final three digits. Read the thousands part, then the hundreds, tens and ones that follow. A space or comma can help group digits; it does not mean a decimal point.

**Say the number in words.**
Our model is “four thousand five hundred and eighteen”. Say the number, point to each matching part and check that you did not turn a digit into the wrong-sized group.

The same method works with fewer or more non-zero places. The number of digits gives a starting clue, but the position of each digit settles its value.

I DO:
4,518 = 4,000 + 500 + 10 + 8.
Words: four thousand five hundred and eighteen.
I match each spoken group with its column, then read the whole count once.

YOU TRY:
Read 4,026 using the columns. Try before comparing.

CHECK:
It is four thousand and twenty-six. The zero column contributes no groups of that size, but still holds its place.

Notice: Do not read every digit as a separate number name when the task asks for the whole number.

**Question:** Which words correctly read 4,518?

1. four thousand six hundred and eighteen
2. four thousand four hundred and eighteen
3. four thousand five hundred and eighteen
4. four thousand five hundred and twenty-eight

Reviewer answer: four thousand five hundred and eighteen

Why: Four thousand five hundred and eighteen matches the thousands part and the remaining hundreds, tens and ones. The other readings change a digit’s value.

### Help with this step

1. Look at how the thousands chunk and final digits are read.
2. Point to the matching place while saying each number-word part.
3. Read the large group first, then the remaining hundreds, tens and ones; match the result back to the chart.

## Teaching 3: Keep zero as a place holder

### In-site episode: Read and count whole numbers in action

Pip: I am practising how to keep zero as a place holder. I need to track the value, not just copy digits.
Juno: Zero can hold an empty column.
It says there are no groups of that size. It is still important because it keeps the other digits in their intended places. Deleting an internal zero shifts later digits and changes the value.
Pip: 4,026 = 4,000 + 20 + 6.
I preserve its zero column in the numeral. Omitting a zero term from the sum does not allow me to omit the place from the numeral.
Juno: Pause and try a fresh example with the same check. Explain what stays unchanged or which value relationship settles the result.

Learner pause: the final line pauses before continuing.

**Zero can hold an empty column.**
It says there are no groups of that size. It is still important because it keeps the other digits in their intended places. Deleting an internal zero shifts later digits and changes the value.

**Compare two readings.**
Read 4,026 in the chart. Identify the zero column before saying the complete number. It does not make the entire count zero. It only marks an empty place within the count.

**Write from words with the same care.**
Write the needed place columns first. Fill each stated group, then use zero for a column with no group. Check the result by reading it back. This is safer than writing only the non-zero digits you hear.

When using expanded form, you can omit a zero term because it adds nothing. When writing the numeral, preserve the column itself.

I DO:
4,026 = 4,000 + 20 + 6.
I preserve its zero column in the numeral. Omitting a zero term from the sum does not allow me to omit the place from the numeral.

YOU TRY:
Write “four thousand and twenty-six” from its place groups, then read your result back.

CHECK:
The numeral is 4,026. Compare every column, not just the digits you pronounced.

Notice: A place holder is part of the numeral’s structure. Empty is not the same as missing.

**Question:** Why keep an internal zero when writing a whole number?

1. It makes all other digits worthless
2. It means the whole count is zero
3. It is only decoration
4. It preserves the positions of the other digits

Reviewer answer: It preserves the positions of the other digits

Why: The zero marks an empty place and keeps later digits in their intended columns. Removing it changes those positions.

### Help with this step

1. Find the empty column in the model numeral.
2. Keep every place position, even when it contributes no groups.
3. Write the columns first, fill stated groups and put a zero in an empty column before reading back.

## Teaching 4: Cross a counting boundary and check

**One more can change several digits.**
When the ones reach nine, the next unit completes a ten. When every lower column reaches nine, the next unit completes the next larger group. Think about bundling rather than simply putting an extra digit at the end.

**Use a known boundary.**
After 9,999 comes 10,000. The lower nines regroup into one new leading unit. The zeroes show that no leftover smaller groups remain. The count increases by one, not by a whole extra set of unrelated digits.

**Check in both directions.**
Count one forward and one back. If the previous number returns, the step fits. Explain the changed groups so you know why the written change happened.

When a task asks you to count, check its step size too. Counting by one and counting by ten are different jobs; do not silently change the step.

I DO:
9,998, 9,999, 10,000.
I bundle the completed lower groups. Backwards: 10,000, 9,999, 9,998.

YOU TRY:
What is one more than 4,518? Which column changes?

CHECK:
It is 4,519. Only the final ones digit changes here because no lower group is completed. A boundary can change more columns, but not every counting step does.

Notice: Count the units and explain regrouping. Attaching a zero would multiply a number by ten, not add one.

**Question:** What comes immediately after 9,999 when counting by one?

1. 10,000
2. 10,009
3. 9,998
4. 100,000

Reviewer answer: 10,000

Why: 10,000 is one greater than 9,999; the completed lower groups regroup into the next place.

### Help with this step

1. Look at the count just before the new leading place.
2. Track which lower groups become complete when one unit is added.
3. Regroup the completed groups, write the leftover zeroes and count one back to check.

## Put it all together

I DO: Complete a connected read and count whole numbers record.
Target numeral: 4,518. Words: four thousand five hundred and eighteen.
Standard partition: 4,000 + 500 + 10 + 8.
Hundreds digit: 5; value: 500.
Another partition: 4,418 + 100 = 4,518.
Comparison: 4,518 > 4,026. I compare matching places from the left; the first unequal place decides. The difference is 492.
Ascending set: 4,026, 4,518, 4,618.

WHY THE REPRESENTATIONS AGREE
The written numeral, words and expanded sum describe the same place groups. The non-standard partition also returns the same total. Comparing uses those group values, not only the shape of a single digit.

COMMON MISTAKE AND FIX
Writing the hundreds digit’s value as 5 loses its unit size. I change the value label to 500. Another possible error is deleting the zero in 4,026; I keep its column and reread the whole count.

CHECK
I rebuild the numeral from its non-zero terms and read the comparison in both directions. If a check disagrees, I revisit the relevant column before changing unrelated digits.

Diagram: A place-value chart for 4,026. Thousands: digit 4, value 4,000, Hundreds: digit 0, value 0, Tens: digit 2, value 20, Ones: digit 6, value 6.

A digit’s column gives its value.

### Help with this step

1. Read the numeral and expanded form together.
2. Match each part of the sum to its place column.
3. Rebuild the same total, then use matching place values to check the comparison.
