## Teaching 1: Define integers and the reference zero

**An integer is a whole-number value with a sign when needed.**
The integers include negative whole numbers, zero and positive whole numbers: for example, negative three, zero and four. Fractions such as one half are not integers. The word whole in this explanation concerns the size of the unit, not a rule that the sign must be positive.

**Zero is a reference point.**
A signed value describes a position relative to zero. On a temperature scale, a negative reading is below zero degrees Celsius. In a floor model, negative levels can be below the ground reference. Choose and state the reference before interpreting the sign.

**Positive and negative are directions from the reference.**
A plus sign can be written for a positive value, but it is often omitted. A minus sign attached to a numeral marks a negative value. Zero is neither positive nor negative.

Do not assume that negative means physically impossible or that it always means bad. Its meaning depends on the chosen reference and context.

I DO:
I use ground level as zero. A position two levels below it is −2; three levels above it is +3, usually written 3. A ground-level position is 0.
Temperature example: −4 °C is four degrees below zero, not a count of negative objects.

YOU TRY:

CHECK:

## Teaching 2: Place signed values on a number line

**Equal spacing represents equal differences.**
On this line, each interval is one unit. Zero separates positive positions on the right from negative positions on the left. Read the labels and scale before placing a point.

**Position gives the value.**
To place negative three, start at zero and count three equal intervals left. To place positive three, count three intervals right. Both are equally far from zero, but they have different values because they are on different sides.

**Do not count a starting tick as a movement.**
Starting at zero, the first interval left ends at negative one. Count intervals travelled, not the number of tick marks you see including the start.

If a line uses steps of two or five, the same number of intervals represents a different distance. The scale must match the values you assign.

I DO:
Start at 0. One interval left reaches −1; a second reaches −2; a third reaches −3.
To place 4, start again at 0 and move four intervals right.

YOU TRY:
Place −2 on a line with one-unit intervals and explain the direction.

CHECK:
It is two intervals left of zero. Counting the starting tick as the first unit would place it incorrectly.

Notice: Read the scale first. A drawing without labelled units is not enough to determine a value.

**Question:** On a one-unit number line, how is −3 located from zero?

1. Three intervals right
2. At the zero tick
3. Six intervals right
4. Three intervals left

Reviewer answer: Three intervals left

Why: A negative position lies left of zero, and the magnitude three gives three one-unit intervals.

### Help with this step

1. Look at the line’s unit intervals and zero label.
2. Count movements from the reference rather than counting the starting tick.
3. Use the sign for direction and the numeral for the number of equal units.

**Absolute value measures distance from zero.**
Distance is non-negative. The notation |−3| means the distance of negative three from zero, which is three. Similarly, |3| is three. The bars here are absolute-value notation, not brackets telling you to change every sign in an expression.

**Opposites have equal distance and opposite sides.**
Three and negative three are opposites. Their number-line points mirror each other across zero. Zero is its own opposite.

**Distance does not decide ordinary order.**
Negative five is farther from zero than negative two, but it lies farther left and is a smaller value. Ask whether the task concerns signed value, distance or an opposite before answering.

Use the number line when the notation is unfamiliar. First identify the point, then count its distance to zero.

I DO:
Value: −5. Distance from zero: |−5| = 5. Opposite: 5.
For 2, the distance is 2 and the opposite is −2.

YOU TRY:
Find the distance and opposite for −4. Give the two answers separate labels.

CHECK:
Distance: 4. Opposite: 4. These happen to have the same numeral in this example, but they are answers to different questions. For positive four, distance stays four while its opposite is negative four.

Notice: Absolute value is distance. It does not mean that negative values are larger in ordinary order.

**Question:** What does |−5| describe?

1. A signed value smaller than −5
2. A distance of five units from zero
3. A rule that −5 is greater than 2
4. A fractional interval

Reviewer answer: A distance of five units from zero

Why: Absolute value gives the non-negative distance from zero, which is five units for −5.

### Help with this step

1. Find the signed point before thinking about distance.
2. Separate the labels value, distance and opposite.
3. Count to zero for distance; reflect across zero for the opposite.

## Teaching 4: Translate a context without changing its reference

**A signed model needs a consistent zero.**
If a water-level chart uses a marked line as zero, below that mark is negative and above it is positive. Keep that reference for every reading in the same comparison.

**Write units with the value.**
A signed height in metres and a temperature in degrees Celsius describe different measurements. The same integer can appear in both, but the unit and reference supply the interpretation.

**Check the words against the sign.**
“Below” and “above” often suggest directions, but only after you know the reference. A statement five metres below a roof is not automatically five metres below sea level.

Explain your model in one sentence: reference, position and unit. This makes a signed answer meaningful and checkable.

I DO:
A marker is the zero on a depth display. A reading −3 m means three metres below that marker. I do not claim it is below sea level unless that is the actual reference.

YOU TRY:
A platform is two metres above a marked zero. Write the value and explain it.

CHECK:
+2 m, or 2 m, is two metres above the stated marker. Both positive notations preserve the meaning.

Notice: Keep the same reference throughout. A minus sign alone cannot tell the entire context.

**Question:** What should accompany a signed measurement explanation?

1. Only the number of letters
2. An invented reference
3. Its reference and unit
4. A statement that negative is impossible

Reviewer answer: Its reference and unit

Why: The reference and unit explain what the signed value measures and how its position is interpreted.

### Help with this step

1. Reread the reference named in the scenario.
2. Identify the direction and measurement unit separately.
3. Write a signed value, then explain its position relative to that same reference.
